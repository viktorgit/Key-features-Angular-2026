Same engineering ideas.

The original ideal-project introduced RxJS, dependency injection, stores, themes, lazy modules and an email-form library.

Here those ideas become standalone components, signal stores, lazy routes, a deferred view and a separately packaged library. RxJS still handles asynchronous work.
